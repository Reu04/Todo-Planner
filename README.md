# Todo List

Простой Todo List, реализованный на нативном JavaScript с использованием [Vite](https://vitejs.dev/) для сборки.  

---

## Технологии
- JavaScript
- HTML5 & CSS3
- Vite

---

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/ваш-логин/todo-list.git
cd todo-list
```

2. Установите зависимости:
```bash
npm install
```

3. Для запуска приложения в режиме разработки:
```bash
npm run dev
```

4. Для сборки приложения для продакшена:
```bash
npm run build
```
